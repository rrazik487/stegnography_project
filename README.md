# Steganography Web Tool

This is a simple **Steganography Tool** that allows users to:
- **Embed secret messages** inside images.
- **Extract hidden messages** from stego images.

## **🌟 Features**
✅ Works completely **in the browser** (No backend required)  
✅ Supports **PNG images**  
✅ Uses **Least Significant Bit (LSB) Steganography**  
✅ Secure message embedding & extraction  

## **🚀 Live Demo**
[🔗 Click here to view the live app](https://github.com/rrazik487/stegnography_project/)

## **📌 How to Use**
### **Embedding a Message**
1. Click **"Choose File"** and upload a PNG image.
2. Enter a **secret message**.
3. Click **"Embed & Download"**.
4. Download the stego image.

### **Extracting a Message**
1. Click **"Choose File"** and upload a **stego image**.
2. Click **"Extract Message"** to reveal the secret text.
